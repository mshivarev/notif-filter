# Без рекламы — фильтр рекламных уведомлений для Android

Читает все входящие уведомления (NotificationListenerService), распознаёт рекламные
(акции, скидки, промокоды, распродажи, «только сегодня», каналы Promo/Акции) и убирает их из шторки.
Скрытое сохраняется в журнал на 30 дней. Работает полностью офлайн, без разрешения на интернет.

## Установка на телефон
1. Скопируйте `dist/bez-reklamy-1.0.apk` на телефон и откройте (разрешите установку из этого источника).
2. Откройте «Без рекламы» → «Открыть настройки» → включите доступ к уведомлениям.
   Если Android 13+ пишет «Ограниченная настройка»: Настройки → Приложения → Без рекламы → ⋮ →
   «Разрешить ограниченные настройки», затем снова включите доступ.
3. Снимите ограничение батареи (кнопка на главном экране); на Xiaomi/Huawei/Honor — включите автозапуск.
4. Первые дни можно включить «Тестовый режим»: реклама только пишется в журнал, но не удаляется.

## Как настраивать
- **Журнал → Скрытые**: нажмите на запись → «Открыть» / «Не реклама: доверять приложению» / «Удалить».
- **Журнал → Пропущенные**: если проскочила реклама → «Блокировать приложение» или «Добавить слово».
- **Приложения**: для каждого — Авто (правила) / Доверять / Блок.
- **Правила**: чувствительность, свои слова (+реклама / −не реклама), проверка произвольного текста.

## Как устроено
- `classify/Rules.kt` — словарь признаков RU/EN с весами (+ сильные/средние, − служебные: коды, заказы, платежи).
- `classify/PromoClassifier.kt` — сумма баллов ≥ порога и хотя бы один содержательный признак.
- `service/FilterListenerService.kt` — фильтрация, `cancelNotification`, журнал.
- `data/Repo.kt` — SQLite (журнал, режимы приложений, свои слова) + SharedPreferences.
